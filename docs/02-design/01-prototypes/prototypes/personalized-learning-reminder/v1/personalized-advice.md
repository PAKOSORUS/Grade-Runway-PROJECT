## จุดประสงค์ของหน้าจอ

ตอบ US2/BR3 และ Feature #4: แสดงคำแนะนำที่ **คำนวณเฉพาะบุคคล** จากข้อมูลย้อนหลังของนักศึกษาแต่ละคน ในรูปแบบ actionable (บอกว่าควรทำอะไรต่อ ไม่ใช่แค่บอกปัญหา)

## องค์ประกอบ (Components)

| โซน | คอมโพเนนต์ (อ้างอิง DESIGN.md) | เนื้อหา/พฤติกรรม |
|---|---|---|
| Header | Navigation (3.7) | ชื่อหน้า |
| กล่องที่มาของข้อมูล | Highlight พื้น `--color-accent-gold-100` | บอกว่าคำนวณจากข้อมูลช่วงใด เพื่อสื่อว่าเป็นคำแนะนำเฉพาะบุคคล |
| การ์ดคำแนะนำ | Card (3.2) | หัวการ์ด `--font-size-h2` เนื้อหาสำคัญใช้ `--font-size-body-lg` (2.2) จัดเรียงตามความเกี่ยวข้องกับตัวแปรที่เสี่ยง |
| ป้ายตัวแปรที่เกี่ยวข้อง | Badge (3.3) | ระดับเสี่ยงของตัวแปรนั้น พร้อมไอคอน/ข้อความ |
| ปุ่มรับทราบ | Button Ghost (3.1) | ปิดคำแนะนำชุดนี้ ไม่ส่งผลต่อการคำนวณ (ไม่มี feedback loop ตาม spec) |

ตัวอย่างน้ำเสียง (4.2): "ช่วงสามสัปดาห์ที่ผ่านมาคุณขาดคาบเช้าบ่อยกว่าคาบอื่น ลองจัดเวลานอนหรือเตรียมของคืนก่อนเรียนดูนะ"

## States

- **Default:** การ์ดคำแนะนำตามตัวแปรที่เสี่ยง เรียงตามความสำคัญ
- **ข้อมูลย้อนหลังไม่พอ (edge case หลัก):** แสดงการ์ด "ข้อมูลยังไม่พอสำหรับคำแนะนำเฉพาะตัว — ระบบต้องการข้อมูลผลการเรียนอย่างน้อย {จำนวนที่ระบบกำหนด}" พร้อมคำแนะนำทั่วไปที่ติดป้าย "คำแนะนำทั่วไป ไม่ใช่เฉพาะบุคคล" ชัดเจน _(ต้องการข้อมูลเพิ่มเติมจากผู้ใช้: spec ไม่ระบุ fallback)_
- **Empty state (4.5):** ไม่มีตัวแปรใดเสี่ยง — "ตอนนี้ผลการเรียนของคุณอยู่ในเกณฑ์ปกติ ระบบจะแสดงคำแนะนำเมื่อพบแนวโน้มที่ควรปรับ" พร้อมป้ายสถานะ "ปกติ" (success + ไอคอน)
- **Loading/Error:** skeleton การ์ด / "คำนวณคำแนะนำไม่สำเร็จ ลองใหม่อีกครั้งภายหลัง"

## Interaction & Edge Cases

- นักศึกษาที่เพิ่งเข้าเรียน — ใช้ state ข้อมูลไม่พอข้างต้น
- เข้าเงื่อนไขหลายตัวแปรพร้อมกัน — แสดงการ์ดต่อตัวแปร จัดลำดับตามระดับเสี่ยง _(ต้องการข้อมูลเพิ่มเติมจากผู้ใช้)_
- ไม่มีกลไกติดตามว่านักศึกษาทำตามคำแนะนำหรือไม่ (spec ไม่ระบุ) จึงไม่มีฟอร์มรายงานผลหรือ checklist ติดตาม
