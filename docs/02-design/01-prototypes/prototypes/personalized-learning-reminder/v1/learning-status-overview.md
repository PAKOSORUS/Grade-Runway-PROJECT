## จุดประสงค์ของหน้าจอ

เป็นหน้าแรกของนักศึกษา แสดงตัวแปรที่ระบบติดตามทั้ง 4 ตัว (เกรด, การเข้าเรียน, การส่งงาน/แบบทดสอบ, แนวโน้มผลการเรียน) พร้อมระดับความเสี่ยงของแต่ละตัว ตอบ Feature #1 และ #2 และเป็นจุดเริ่มไปยังการแจ้งเตือน คำแนะนำ และสรุปรายสัปดาห์

## องค์ประกอบ (Components)

| โซน | คอมโพเนนต์ (อ้างอิง DESIGN.md) | เนื้อหา/พฤติกรรม |
|---|---|---|
| Header / Nav | Navigation (3.7) | Active tab ขีดเส้นใต้ `--color-accent-gold-500`; มือถือใช้ bottom tab bar (4.3) พร้อมจุดแสดงจำนวนแจ้งเตือนที่ยังไม่อ่านบนแท็บ "แจ้งเตือน" |
| Banner สรุปรายสัปดาห์ | Inline banner (3.4) | พื้น `--color-info-500` โทนอ่อน ไม่ auto-dismiss ปุ่ม "ดูสรุป" ไปหน้า weekly-summary |

| คำแนะนำใกล้ป้ายความเสี่ยง | Card + ข้อความ `--font-size-body` | การ์ดที่เป็น warning/danger มีลิงก์ "ดูแนวทางแก้ไข" ในการ์ดเดียวกันเสมอ (4.1) |
| ปุ่มหลัก | Button Primary (3.1) | "ดูคำแนะนำสำหรับฉัน" ไปหน้า personalized-advice (พื้นที่กด >= 44x44px) |

## States

- **Default:** การ์ดทั้ง 4 ใบแสดงค่าและระดับ พร้อมเวลา "อัปเดตล่าสุด"
- **Empty state (4.5):** นักศึกษาใหม่ที่ยังไม่มีข้อมูลเกรด/การเข้าเรียน — "ยังไม่มีข้อมูลผลการเรียนในระบบ ข้อมูลจะปรากฏหลังมีการบันทึกเข้าเรียนหรือส่งงานครั้งแรก" _(ต้องการข้อมูลเพิ่มเติมจากผู้ใช้: ที่มาของข้อมูล)_
- **Loading:** skeleton ของการ์ด 4 ใบ
- **Error:** "โหลดข้อมูลผลการเรียนไม่สำเร็จ ลองรีเฟรชอีกครั้ง หากยังไม่ได้ผลให้ติดต่อผู้ดูแลระบบ" พร้อมปุ่ม Secondary "ลองใหม่"

## Interaction & Edge Cases

- กดการ์ดใดๆ เพื่อดูรายละเอียดตัวแปรนั้น (เชื่อมไป alert-detail ถ้ามีแจ้งเตือนของตัวแปรนั้น)
- เข้าเงื่อนไขเสี่ยงหลายตัวแปรพร้อมกัน — แสดงแถบ danger สรุปบนสุดของรายการการ์ด ลำดับความสำคัญภายในยังไม่ระบุใน spec จึงเรียงตามระดับความเสี่ยง _(ต้องการข้อมูลเพิ่มเติมจากผู้ใช้)_
- นักศึกษาที่มีข้อมูลย้อนหลังไม่พอ — การ์ด "แนวโน้ม" แสดง "ข้อมูลยังไม่พอสำหรับดูแนวโน้ม" แทนค่า
- แอดมินเปลี่ยนเกณฑ์ — ค่าเกณฑ์ในการ์ดอัปเดตตามการตั้งค่าล่าสุดโดยไม่ hardcode
