## จุดประสงค์ของหน้าจอ

ตอบ US3 และ Feature #5 (Should have): สรุปสถานการณ์การเรียนรายสัปดาห์ นอกเหนือจากแจ้งเตือนทันที พร้อมส่วนเทียบกับสัปดาห์ก่อนเพื่อประเมินความคืบหน้า (เนื้อหาในสรุปเป็นสมมติฐาน เพราะ spec ไม่ระบุรายละเอียด)

## องค์ประกอบ (Components)

| โซน | คอมโพเนนต์ (อ้างอิง DESIGN.md) | เนื้อหา/พฤติกรรม |
|---|---|---|
| Header + ตัวเลือกสัปดาห์ | Navigation (3.7), ปุ่ม Ghost | เลื่อนดูสรุปสัปดาห์ก่อนหน้า |
| ข้อความภาพรวม | Inline banner (3.4) | พื้น `--color-info-500` โทนอ่อน ไม่ auto-dismiss |
| การ์ดต่อตัวแปร | Card (3.2) | แถบซ้าย 4px ตามระดับ (`--color-success-500`/`--color-warning-500`/`--color-danger-500`) ตัวเลขใช้ tabular-nums |
| ตัวบ่งชี้การเปลี่ยนแปลง | Badge (3.3) | "ดีขึ้น"/"เท่าเดิม"/"ลดลง" ต้องมีลูกศรไอคอนและข้อความ ไม่ใช้สีอย่างเดียว (4.4) |
| ปุ่มไปคำแนะนำ | Button Secondary (3.1) | ไป personalized-advice |

## States

- **Default:** สรุปสัปดาห์ล่าสุดพร้อมเทียบสัปดาห์ก่อน
- **Empty state (4.5):** สัปดาห์แรกที่ยังไม่มีสัปดาห์ก่อนให้เทียบ — "ยังไม่มีข้อมูลสัปดาห์ก่อนหน้าสำหรับเปรียบเทียบ จะแสดงผลเปรียบเทียบตั้งแต่สัปดาห์ถัดไป" และสัปดาห์ที่ไม่มีสรุป — "สัปดาห์นี้ยังไม่มีข้อมูลเพียงพอสำหรับสร้างสรุป"
- **Loading/Error:** skeleton / "โหลดสรุปไม่สำเร็จ ลองใหม่อีกครั้ง"

## Interaction & Edge Cases

- สลับสัปดาห์ด้วยปุ่มก่อนหน้า/ถัดไป (ปุ่มถัดไป disabled เมื่ออยู่สัปดาห์ล่าสุด ใช้สไตล์ disabled ตาม 3.1)
- ตัวแปรที่ลดลงต้องมีข้อความแนะนำสั้นๆ และลิงก์ไปคำแนะนำอยู่ในการ์ดเดียวกัน (4.1)
- วัน/เวลาที่ส่งสรุป และเนื้อหาที่เปรียบเทียบ spec ไม่ระบุ — ใช้สมมติฐานว่าเทียบ 4 ตัวแปรหลักกับสัปดาห์ก่อน _(ต้องการข้อมูลเพิ่มเติมจากผู้ใช้)_
