# Prototype: ช่องแชทรีวิวและแนะนำวิธีการเรียนจากนักศึกษาเกรดสูง

เก็บ Prototype (รายการหน้าจอ + wireframe) ของฟีเจอร์ช่องแชทที่ให้นักศึกษาเกรดสูง/ผ่านเกณฑ์ผลการเรียนเข้ามารีวิวหรือแนะนำวิธีการเรียนให้นักศึกษาคนอื่นในวิชาเดียวกัน (peer-to-peer) ภายใต้การควบคุมของแอดมิน (approve ผู้แนะนำ + pre-moderation ทุกข้อความ)
