## จุดประสงค์ของหน้าจอ

อุดช่องว่างที่ User Journey ของผู้แนะนำระบุว่า "ไม่มี UI ชัดเจนที่นักศึกษาเห็นสถานะระหว่างรอ" การอนุมัติจากแอดมิน (BR1) หน้านี้ให้นักศึกษาที่ระบบเสนอชื่อแล้วติดตามสถานะคำขอของตนเองได้ทุกขั้น (ระบบเสนอชื่อ → รอแอดมินอนุมัติ → ผลอนุมัติ/ปฏิเสธ)

## องค์ประกอบ (Components)

|---|---|---|
| Header | Navigation (3.7) | ชื่อหน้า "สิทธิ์ผู้แนะนำของฉัน" |
| การ์ดสถานะต่อวิชา | Card (3.2) | ใช้แถบสีซ้าย 4px ตามสถานะ (`--color-warning-500` / `--color-success-500` / `--color-danger-500`) ตามกฎการ์ดความเสี่ยง (3.2) |
| Badge สถานะ | Badge (3.3) | รอการอนุมัติ: พื้น/ข้อความ `--color-warning-500` โทนอ่อน; อนุมัติแล้ว: badge ทองผู้แนะนำ (`--color-accent-gold-100`/`--color-accent-gold-700`); ถูกปฏิเสธ: `--color-danger-500` โทนอ่อน |

## States

- **Default (มีคำขออยู่ระหว่างดำเนินการ/ผ่านแล้ว):** แสดงการ์ดตามสถานะจริงของแต่ละวิชา
- **Empty state (4.5):** ถ้ายังไม่เคยถูกระบบเสนอชื่อในวิชาใดเลย — อธิบายสาเหตุและขั้นตอนถัดไป เช่น "คุณยังไม่ถูกเสนอชื่อเป็นผู้แนะนำในวิชาใด ระบบจะประมวลผลผลการเรียนของคุณเมื่อครบเกณฑ์ที่แต่ละวิชากำหนด" _(ดึงค่าจริงจากเกณฑ์ที่ตั้งค่าไว้ ไม่ hardcode ตาม 4.1)_
- **สถานะถูกปฏิเสธ (reject):** แสดงเหตุผลสั้นๆ ถ้ามี พร้อมข้อความบอกว่าจะได้รับการพิจารณาใหม่เมื่อใด _(ต้องการข้อมูลเพิ่มเติมจากผู้ใช้)_

## Interaction & Edge Cases

- ระบบเสนอชื่อแล้วแต่แอดมินไม่อนุมัติ (reject) — ยังไม่ระบุว่ามีการแจ้งเหตุผลหรือให้ยื่นใหม่ได้หรือไม่ ในเวอร์ชันนี้ให้แสดงข้อความเหตุผลแบบทั่วไปพร้อมหมายเหตุ `_(ต้องการข้อมูลเพิ่มเติมจากผู้ใช้)_`
- นักศึกษาที่เคยผ่านเกณฑ์แล้วผลการเรียนภาคถัดไปตกต่ำกว่าเกณฑ์ — ยังไม่ระบุว่าจะถูกถอนสิทธิ์หรือไม่ จึง **ไม่ออกแบบสถานะ "ถูกถอนสิทธิ์" ในเวอร์ชันนี้** `_(ต้องการข้อมูลเพิ่มเติมจากผู้ใช้)_`
- ช่องทางแจ้งผล (push/email/in-app เท่านั้น) ยังไม่ระบุใน spec — สมมติฐาน: ใช้ในแอปเท่านั้น (Notification pattern 3.4)
