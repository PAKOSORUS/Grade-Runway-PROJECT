## จุดประสงค์ของหน้าจอ

ให้แอดมินกำหนด/ปรับเกณฑ์ผลการเรียน (เกรดรายวิชาหรือ GPA สะสม) ที่ระบบใช้ประมวลผลเพื่อเสนอชื่อผู้แนะนำในแต่ละวิชา ตาม BR1 ข้อ 1 ที่ระบุว่าค่าตัวเลขต้อง configurable และ DESIGN 4.1 ที่กำหนดว่า "Configurable ต้องสะท้อนใน UI" — หน้าจออื่นๆ ที่แสดงเกณฑ์ต้องดึงค่าจริงจากหน้านี้เสมอ ไม่ hardcode

## องค์ประกอบ (Components)

| โซน | คอมโพเนนต์ (อ้างอิง DESIGN.md) | เนื้อหา/พฤติกรรม |
|---|---|---|
| Header/Nav | Navigation (3.7) | เมนูแอดมิน |
| ฟอร์มตั้งค่า | Form/Input, Select, Radio (3.6) | Label อยู่เหนือ input เสมอ (ไม่ใช้ placeholder แทน label); focus เปลี่ยนขอบเป็น `--color-primary-600` หนา 2px |
| ปุ่ม action | Button Primary "บันทึก" (3.1) / Button Secondary "ยกเลิก" (3.1) | ตามกฎ variant ปุ่มมาตรฐาน |
| รายการ/ตารางเกณฑ์ปัจจุบัน (mobile) | Card (3.2) | แสดงวิชา, ประเภทเกณฑ์, ค่าปัจจุบัน แทนตารางบนจอเล็ก |
| ปุ่มแก้ไขรายแถว | Button Ghost/Text (3.1) | Action เสริมไม่ต้องเน้น |
| ข้อความ error ของ input | Form error text (3.6) | `--color-danger-500`, `--font-size-caption` เช่น ค่าที่กรอกอยู่นอกช่วงที่ยอมรับได้ |

## States

- **Default:** แสดงตาราง/รายการเกณฑ์ปัจจุบันของทุกวิชาที่เคยตั้งค่าไว้
- **Empty state (4.5):** ยังไม่มีวิชาใดถูกตั้งค่าเกณฑ์เลย — อธิบายสาเหตุและขั้นตอนถัดไป เช่น "ยังไม่มีวิชาใดตั้งค่าเกณฑ์ผู้แนะนำ กรุณาเลือกวิชาด้านบนเพื่อเริ่มตั้งค่า"
- **Validation error:** กรอกค่าเกณฑ์ไม่ถูกต้อง (เช่น ค่าติดลบ หรือเกินช่วงเกรด/GPA ที่เป็นไปได้) — แสดงข้อความ error ใต้ input ตามกฎ 3.6
- **Loading/Error:** โหลด/บันทึกไม่สำเร็จ — ระบุสาเหตุ+วิธีแก้ตาม 4.5

## Interaction & Edge Cases

- ค่าเริ่มต้นของเกณฑ์ต่อวิชาไม่ระบุใน spec — สมมติฐาน: ไม่มีค่าเริ่มต้น (default) ให้ admin ต้องกรอกเองก่อนระบบจะเริ่มเสนอชื่อผู้แนะนำในวิชานั้น `_(ต้องการข้อมูลเพิ่มเติมจากผู้ใช้)_`
- ประเภทเกณฑ์รองรับทั้ง "เกรดรายวิชา" และ "GPA สะสม" ตามถ้อยคำใน BR1 ("อิงตามเกรดของวิชาหรือ GPA สะสม") — ยังไม่ระบุว่าใช้ได้ทั้งสองแบบพร้อมกันในวิชาเดียวหรือเลือกได้แบบเดียว เวอร์ชันนี้ออกแบบให้เลือกได้ทีละแบบต่อวิชา (radio button)
- การเปลี่ยนเกณฑ์กลางภาคการศึกษาจะมีผลย้อนหลังกับผู้แนะนำที่อนุมัติไปแล้วหรือไม่ — ไม่ระบุใน spec `_(ต้องการข้อมูลเพิ่มเติมจากผู้ใช้)_`
