## TS-10: หน้าสรุปภาพรวมรายสัปดาห์แสดงข้อมูลครบถ้วน

**อ้างอิงจาก:** TC-10 / AC-3 (main flow) / BR4 — "สรุปภาพรวมรายสัปดาห์นอกเหนือจากการแจ้งเตือนทันที"
**Priority:** Medium
**ประเภท:** Positive

### วัตถุประสงค์
ยืนยันว่าหน้าสรุปภาพรวมรายสัปดาห์แสดงข้อมูลเกรด/การเข้าเรียน/การส่งงาน/แนวโน้มของสัปดาห์นั้นครบถ้วน ตามที่ระบุใน BR4

### Precondition
- มีบัญชีผู้ใช้ (Persona #1–#4 ตัวใดก็ได้) ที่มีข้อมูลผลการเรียนของสัปดาห์ที่ผ่านมาครบถ้วนในระบบ

### Test Data / Environment
| รายการ | ค่าของสัปดาห์ล่าสุด |
|---|---|
| เกรด/คะแนนเก็บ | มีข้อมูลบันทึกไว้ในสัปดาห์นั้น |
| อัตราเข้าเรียนของสัปดาห์ | มีข้อมูลบันทึกไว้ |
| จำนวนงานที่ส่ง/ไม่ส่งของสัปดาห์ | มีข้อมูลบันทึกไว้ |
| แนวโน้ม (trend) เทียบข้อมูลก่อนหน้า | มีข้อมูลเพียงพอสำหรับคำนวณ |

### ขั้นตอนทดสอบ

| # | การกระทำ | Input | ผลลัพธ์ที่คาดหวัง |
|---|---|---|---|
| 1 | Login เข้าระบบด้วยบัญชีที่มีข้อมูลสัปดาห์ล่าสุดครบ | บัญชีทดสอบ | เข้าสู่ระบบสำเร็จ |
| 2 | เปิดหน้าสรุปภาพรวมสถานการณ์การเรียนรายสัปดาห์ | — | หน้าโหลดสำเร็จ ไม่มี error |
| 3 | ตรวจสอบว่าหน้าแสดงข้อมูลเกรด/คะแนนของสัปดาห์นั้น | — | แสดงข้อมูลเกรด/คะแนนตรงกับที่บันทึกไว้ |
| 4 | ตรวจสอบว่าหน้าแสดงข้อมูลอัตราเข้าเรียนของสัปดาห์นั้น | — | แสดงอัตราเข้าเรียนตรงกับที่บันทึกไว้ |
| 5 | ตรวจสอบว่าหน้าแสดงข้อมูลการส่งงานของสัปดาห์นั้น | — | แสดงจำนวนงานที่ส่ง/ไม่ส่งตรงกับที่บันทึกไว้ |
| 6 | ตรวจสอบว่าหน้าแสดงแนวโน้ม (trend) ของผลการเรียน | — | แสดงแนวโน้มอย่างน้อย 1 รูปแบบ (เช่น กราฟ/ไอคอนขึ้น-ลง) |

### ผลลัพธ์รวมที่คาดหวัง (Expected Result)
หน้าสรุปรายสัปดาห์แสดงข้อมูลทั้ง 4 หมวด (เกรด, การเข้าเรียน, การส่งงาน, แนวโน้ม) ของสัปดาห์นั้นครบถ้วนตรงกับข้อมูลจริงที่บันทึกไว้

### Postcondition
ไม่ต้อง reset ข้อมูล (เป็นการอ่านข้อมูลเท่านั้น)

### Dependency
ควรมีข้อมูลผลการเรียนที่บันทึกจาก TS-01–TS-04 หรือเทียบเท่าอยู่ในระบบก่อน เพื่อให้มีข้อมูลสัปดาห์ให้แสดงผลจริง

## TS-11: การเปรียบเทียบแนวโน้มกับสัปดาห์ก่อนหน้า

**อ้างอิงจาก:** TC-11 / AC-3 (edge case — เปรียบเทียบสัปดาห์ก่อนหน้า)
**Priority:** Medium
**ประเภท:** Edge

### วัตถุประสงค์
ยืนยันว่าเมื่อมีข้อมูลสรุปทั้งสัปดาห์ปัจจุบันและสัปดาห์ก่อนหน้า หน้าสรุปแสดงการเปรียบเทียบ/แนวโน้มอย่างน้อย 1 ตัวแปร ตามที่ระบุใน User Journey ("ประเมินความคืบหน้าของตัวเองเทียบสัปดาห์ก่อน")

### Precondition
- ผู้ใช้มีข้อมูลสรุปของสัปดาห์ปัจจุบันและสัปดาห์ก่อนหน้าครบทั้งสองสัปดาห์

### Test Data / Environment
| สัปดาห์ | อัตราเข้าเรียน | จำนวนงานที่ส่ง |
|---|---|---|
| สัปดาห์ก่อนหน้า | 85% | ส่งครบ 3/3 |
| สัปดาห์ปัจจุบัน | 90% | ส่งครบ 4/4 |

### ขั้นตอนทดสอบ

| # | การกระทำ | Input | ผลลัพธ์ที่คาดหวัง |
|---|---|---|---|
| 1 | บันทึกข้อมูลสรุปของสัปดาห์ก่อนหน้าตามตาราง Test Data | ค่าตามตารางด้านบน | บันทึกสำเร็จ |
| 2 | บันทึกข้อมูลสรุปของสัปดาห์ปัจจุบันตามตาราง Test Data | ค่าตามตารางด้านบน | บันทึกสำเร็จ |
| 3 | เปิดหน้าสรุปภาพรวมรายสัปดาห์ | บัญชีทดสอบ | หน้าโหลดสำเร็จ |
| 4 | ตรวจสอบส่วนเปรียบเทียบ/แนวโน้มกับสัปดาห์ก่อนหน้า | — | แสดงการเปรียบเทียบอย่างน้อย 1 ตัวแปร (เช่น "อัตราเข้าเรียนเพิ่มขึ้นจาก 85% เป็น 90%") พร้อมทิศทางแนวโน้ม (เพิ่มขึ้น/ลดลง) |

### ผลลัพธ์รวมที่คาดหวัง (Expected Result)
หน้าสรุปรายสัปดาห์แสดงการเปรียบเทียบข้อมูลกับสัปดาห์ก่อนหน้าอย่างน้อย 1 ตัวแปร ให้ผู้ใช้เห็นความคืบหน้าของตนเอง

### หมายเหตุ (สมมติฐาน)
รูปแบบการแสดงผล (กราฟ/ตัวเลข/ไอคอน) ยังไม่ระบุใน spec — เทสนี้ยืนยันเฉพาะว่า "มีการเปรียบเทียบปรากฏ" ไม่ยืนยันรูปแบบ UI ที่แน่นอน ตามคะแนนความมั่นใจต่ำ (2) ที่ระบุใน User Journey

### Postcondition
ไม่ต้อง reset ข้อมูล

### Dependency
ต้องรันหลัง TS-10 (ยืนยันว่าหน้าสรุปพื้นฐานแสดงผลถูกต้องก่อน)
