# Log 2026-08-25

## สร้าง requirement ระบบเตือนและแนะนำแนวทางการเรียน
- สร้างเอกสาร requirement ใหม่: [[../01-requirements/01-spec/20260825-01-personalized-learning-reminder|ระบบเตือนและแนะนำแนวทางการเรียนส่วนบุคคล]] (relationship: `new` — เป็นเอกสาร requirement ฉบับแรกของโปรเจกต์)
- อัปเดต [[../01-requirements/backlog|backlog]] เพิ่มแถวใหม่สำหรับ requirement นี้
- ถามผู้ใช้เพื่อยืนยันรายละเอียด 4 ประเด็น (กลุ่มเป้าหมาย, เงื่อนไขการแจ้งเตือน, ช่องทาง/ความถี่, ลักษณะคำแนะนำ) ก่อนสรุปเอกสาร — ผู้ใช้ระบุให้ตัดสินใจเองในบางประเด็น พร้อมแจ้งเพิ่มว่าต้องการให้ระบบยืดหยุ่นพอนำไปปรับใช้กับบริบทองค์กร/บริษัทได้ในอนาคต (บันทึกไว้เป็น business rule + note ใน scope ว่ายังไม่ implement ในเวอร์ชันนี้)

## สร้าง requirement ช่องแชทรีวิวและแนะนำวิธีการเรียนจากนักศึกษาเกรดสูง
- สร้างเอกสาร requirement ใหม่: [[../01-requirements/01-spec/20260825-02-high-grade-peer-review-chat|ช่องแชทรีวิวและแนะนำวิธีการเรียนจากนักศึกษาเกรดสูง]] (relationship: `new` — ต่างจาก [[../01-requirements/01-spec/20260825-01-personalized-learning-reminder|ระบบเตือนและแนะนำแนวทางการเรียนส่วนบุคคล]] เพราะเป็นการแนะนำจากนักศึกษาด้วยกันเอง ไม่ใช่คำแนะนำอัตโนมัติจากระบบ)
- อัปเดต [[../01-requirements/backlog|backlog]] เพิ่มแถวใหม่ไว้บนสุด
- ถามผู้ใช้เพื่อยืนยัน 4 ประเด็น (เกณฑ์ผู้แนะนำ, รูปแบบการแชท, ขอบเขตการใช้งาน, การกลั่นกรองเนื้อหา) — ผู้ใช้ยืนยันว่าต้องมีแอดมินอนุมัติผู้แนะนำเพิ่มจากที่ระบบเสนอ, เลือกห้องแชทกลุ่มแยกตามรายวิชา, ให้ตัดสินใจขอบเขตเอง (เลือกจำกัดตามรายวิชาให้สอดคล้องกับรูปแบบห้องแชท), และต้องผ่าน pre-moderation ก่อนเผยแพร่ทุกข้อความ

## สร้าง requirement การเก็บ Log กิจกรรมและการปฏิบัติตาม PDPA
- สร้างเอกสาร requirement ใหม่: [[../01-requirements/01-spec/20260825-03-logging-pdpa-compliance|การเก็บ Log กิจกรรมและการปฏิบัติตาม PDPA]] (relationship: `new` — เป็น cross-cutting requirement ที่ครอบคลุมทั้งระบบ ไม่ทับซ้อนกับเอกสารเดิม แต่มีการอ้างอิงกลับไปยัง [[../01-requirements/01-spec/20260825-01-personalized-learning-reminder|ระบบเตือนและแนะนำแนวทางการเรียนส่วนบุคคล]] และ [[../01-requirements/01-spec/20260825-02-high-grade-peer-review-chat|ช่องแชทรีวิวและแนะนำวิธีการเรียนจากนักศึกษาเกรดสูง]] เพราะทั้งสองฟีเจอร์ประมวลผลข้อมูลส่วนบุคคลที่อยู่ภายใต้ PDPA)
- อัปเดต [[../01-requirements/backlog|backlog]] เพิ่มแถวใหม่ไว้บนสุด
- ถามผู้ใช้เพื่อยืนยัน 4 ประเด็น (ระยะเวลาเก็บ log, ระยะเวลาเก็บข้อมูลส่วนบุคคลนักศึกษา, บทบาท Data Controller, กรอบเวลาแจ้งเหตุข้อมูลรั่วไหล) — สรุปได้ว่า: เก็บ log 1 ปี, เก็บข้อมูลนักศึกษาตลอดสถานภาพ+5 ปีหลังจบ, สถาบันการศึกษาเป็น Data Controller (ทีมพัฒนาเป็น Data Processor), แจ้งเหตุข้อมูลรั่วไหลภายใน 72 ชั่วโมง
