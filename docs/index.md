# Docs

รวมเอกสารทั้งหมดของโปรเจกต์ **Grade Runway** เรียงตามลำดับการไหลของงาน ตั้งแต่ความต้องการไปจนถึงบทเรียนที่ได้หลังส่งมอบ:

- [[01-requirements/index|01-requirements]] — ความต้องการของโปรเจกต์ (spec, plan, task)
- [[02-design/index|02-design]] — การออกแบบ (prototype และ technical design)
- [[03-testing/index|03-testing]] — การทดสอบ (test plan และ test result)
- [[04-retrospectives/index|04-retrospectives]] — สรุปบทเรียนหลังจบแต่ละ phase/sprint
- [[05-log/index|05-log]] — บันทึกความเคลื่อนไหวและเหตุการณ์สำคัญแบบเรียงตามเวลา
- [[00-archived/index|00-archived]] — เอกสารเก่าที่เลิกใช้งานแล้วแต่ยังเก็บไว้อ้างอิง

## ลำดับการไหลของงาน

```
01-requirements → 02-design → 03-testing → 04-retrospectives
                                   ↑
                                05-log (บันทึกคู่ขนานตลอดทั้งโปรเจกต์)
```

เริ่มต้นจาก [[01-requirements/index|01-requirements]] เสมอเมื่อมีฟีเจอร์หรือโปรเจกต์ใหม่ แล้วไล่ตามลำดับด้านบนไปเรื่อยๆ ส่วน [[05-log/index|05-log]] ให้บันทึกคู่ขนานไปตลอด ไม่ต้องรอให้จบขั้นตอนใดขั้นตอนหนึ่งก่อน
