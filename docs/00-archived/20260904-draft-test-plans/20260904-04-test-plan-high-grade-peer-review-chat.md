# Test Plan: ช่องแชทรีวิวและแนะนำวิธีการเรียนจากนักศึกษาเกรดสูง

**สร้างจาก:** [[../../01-requirements/01-spec/20260825-02-high-grade-peer-review-chat|ช่องแชทรีวิวและแนะนำวิธีการเรียนจากนักศึกษาเกรดสูง]]
**อ้างอิง Acceptance Criteria:** [[./20260904-03-acceptance-criteria-high-grade-peer-review-chat|Acceptance Criteria]]
**วันที่สร้าง:** 2026-09-04

## ขอบเขตการทดสอบ (Scope)

### อยู่ในขอบเขต (In Scope)
- ห้องแชทกลุ่มแยกตามรายวิชา สำหรับนักศึกษาที่ลงทะเบียนวิชานั้น
- กลไกระบบเสนอชื่อนักศึกษาที่เข้าเกณฑ์ผลการเรียนสูงเป็นผู้แนะนำ/ผู้รีวิว
- ขั้นตอนแอดมินยืนยันความเหมาะสม (approve) ก่อนให้สิทธิ์ผู้แนะนำ
- การตรวจสอบเนื้อหาก่อนเผยแพร่ (pre-moderation) สำหรับทุกข้อความในห้องแชท

### ไม่อยู่ในขอบเขต (Out of Scope)
- การให้คำแนะนำแบบอัตโนมัติจากระบบโดยไม่มีนักศึกษาจริงเป็นผู้ให้คำแนะนำ (ครอบคลุมในเอกสารระบบเตือนและแนะนำแนวทางการเรียนส่วนบุคคล แยกต่างหาก)
- ห้องแชทหรือฟอรัมที่เปิดกว้างข้ามรายวิชา/ทั้งระบบโดยไม่จำกัดขอบเขตวิชา
- ระบบให้คะแนน/รีวิวผู้ให้คำแนะนำ และระบบรายงานเนื้อหาไม่เหมาะสมภายหลังโพสต์ (post-moderation)

## Test Strategy

- **Functional/Manual testing** เป็นหลักสำหรับ user flow ทั้ง 3 persona (ผู้แนะนำ, นักศึกษาทั่วไป, ผู้ดูแลระบบ) เนื่องจากฟีเจอร์เน้น workflow และ role-based permission มากกว่าการคำนวณเชิงซับซ้อน
- **Integration testing** สำหรับกลไกประมวลผลผลการเรียนอัตโนมัติ (batch job เสนอชื่อผู้แนะนำ) และการเชื่อมโยงกับข้อมูลการลงทะเบียนเรียนภาคปัจจุบัน (enrollment) เพื่อยืนยันว่าเกณฑ์ configurable ทำงานถูกต้องกับข้อมูลจริง
- **Access control / permission testing** เฉพาะเจาะจงสำหรับการจำกัดสิทธิ์เข้าห้องแชทตามรายวิชา+ภาคการศึกษา และสิทธิ์บทบาทผู้แนะนำ (mentor role) เนื่องจากเป็น business rule ที่กระทบความปลอดภัยของข้อมูล
- **End-to-end testing** สำหรับ happy path ครบวงจร: ระบบเสนอชื่อ → แอดมิน approve → ผู้แนะนำโพสต์ → pre-moderation → เผยแพร่ → นักศึกษาทั่วไปเห็น/ตอบกลับ
- _(ต้องการข้อมูลเพิ่มเติมจากผู้ใช้: ยังไม่ทราบว่าจะมี automated test suite รองรับหรือทดสอบ manual ทั้งหมด เนื่องจาก spec ยังไม่ได้ลงรายละเอียดทางเทคนิค/สถาปัตยกรรมที่ใช้จริง)_

## Test Data

- **นักศึกษา A** — ลงทะเบียนวิชา X ภาคปัจจุบัน ผลการเรียนเข้าเกณฑ์ผู้แนะนำ (สมมติฐาน: เกรดวิชา ≥ B+ หรือ GPA สะสม ≥ 3.50 — ค่าจริงต้องยืนยันจากผู้ใช้ตามที่ spec ระบุว่ายังไม่กำหนด)
- **นักศึกษา B** — ลงทะเบียนวิชา X ภาคปัจจุบัน ผลการเรียนไม่เข้าเกณฑ์ผู้แนะนำ
- **นักศึกษา C** — ได้รับ approve เป็นผู้แนะนำในวิชา X แล้ว (ใช้ทดสอบการโพสต์ข้อความ)
- **นักศึกษา D** — นักศึกษาทั่วไป ลงทะเบียนวิชา X ภาคปัจจุบัน ไม่มีสิทธิ์ผู้แนะนำ
- **นักศึกษา E** — ลงทะเบียนวิชา Y (คนละวิชากับ X) ใช้ทดสอบการปฏิเสธสิทธิ์เข้าห้องแชทข้ามวิชา
- **นักศึกษา F** — เคยลงทะเบียนวิชา X ในภาคก่อนหน้า แต่ไม่ได้ลงทะเบียนภาคปัจจุบัน (ใช้ทดสอบ negative access)
- **ผู้ดูแลระบบ G** — บัญชีผู้ดูแลระบบสำหรับทดสอบคิวอนุมัติผู้แนะนำและคิว pre-moderation
- **วิชา X, วิชา Y** — รายวิชาตัวอย่างที่มีการตั้งค่าเกณฑ์ผลการเรียนสำหรับเสนอชื่อผู้แนะนำไว้แล้ว
- _(ต้องการข้อมูลเพิ่มเติมจากผู้ใช้: ค่าตัวเลขเกณฑ์เกรด/GPA จริง และรอบเวลาการประมวลผลอัตโนมัติ)_
