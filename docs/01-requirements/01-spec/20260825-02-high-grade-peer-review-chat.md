# ช่องแชทรีวิวและแนะนำวิธีการเรียนจากนักศึกษาเกรดสูง

**วันที่สร้าง:** 2026-08-25
**สถานะ:** New

## ภาพรวม (Overview)

ฟีเจอร์ช่องแชท (chat channel) ที่เปิดให้นักศึกษาที่มีผลการเรียนสูง หรือนักศึกษาที่ผ่านเกณฑ์ผลการเรียนที่ระบบกำหนดไว้ สามารถเข้ามารีวิวหรือแนะนำวิธีการเรียนให้กับนักศึกษาคนอื่นในรายวิชาเดียวกันได้ โดยมีเป้าหมายเพื่อเปิดพื้นที่แลกเปลี่ยนความรู้/ประสบการณ์การเรียนระหว่างนักศึกษาด้วยกันเอง (peer-to-peer) เสริมจากคำแนะนำที่ระบบสร้างขึ้นอัตโนมัติใน [[20260825-01-personalized-learning-reminder|ระบบเตือนและแนะนำแนวทางการเรียนส่วนบุคคล]]

## User Stories / Use Cases

- ในฐานะนักศึกษาที่มีผลการเรียนสูง/ผ่านเกณฑ์ที่ระบบกำหนด ฉันต้องการเข้าไปแนะนำหรือรีวิววิธีการเรียนของฉันในห้องแชทของรายวิชาที่ฉันเรียนอยู่ เพื่อช่วยเหลือเพื่อนนักศึกษาในวิชาเดียวกัน
- ในฐานะนักศึกษาทั่วไป ฉันต้องการเข้าไปอ่าน/สนทนากับนักศึกษาที่ได้เกรดสูงในห้องแชทของรายวิชาที่ฉันเรียน เพื่อขอคำแนะนำแนวทางการเรียนที่ได้ผลจริงและตรงกับวิชานั้นๆ
- ในฐานะระบบ ฉันต้องการประมวลผลรายชื่อนักศึกษาที่เข้าเกณฑ์ผลการเรียนสูงในแต่ละวิชา แล้วเสนอชื่อ (suggest) ให้ผู้ดูแลระบบพิจารณาอนุมัติเป็นผู้แนะนำ/ผู้รีวิวประจำห้องแชทนั้น
- ในฐานะผู้ดูแลระบบ ฉันต้องการตรวจสอบและยืนยันความเหมาะสม (approve) ของรายชื่อที่ระบบเสนอมา ก่อนที่นักศึกษาคนนั้นจะได้รับสิทธิ์เป็นผู้แนะนำในห้องแชท
- ในฐานะผู้ดูแลระบบ ฉันต้องการตรวจสอบเนื้อหาที่ถูกโพสต์ในห้องแชทก่อนเผยแพร่ เพื่อให้มั่นใจว่าคำแนะนำที่ปรากฏเหมาะสมและเป็นประโยชน์

## Business Rules

- ผู้ที่มีสิทธิ์เป็น "ผู้แนะนำ/ผู้รีวิว" ในห้องแชทต้องผ่าน 2 ขั้นตอน:
  1. **ระบบเสนอชื่ออัตโนมัติ** จากเกณฑ์ผลการเรียนของรายวิชานั้น (ระบบแนะนำเกณฑ์เบื้องต้น เช่น อิงตามเกรดของวิชาหรือ GPA สะสม — ค่าตัวเลขที่แน่นอนต้องกำหนดในขั้นตอนออกแบบถัดไป และควรเป็นค่าที่ configurable เช่นเดียวกับแนวทางใน [[20260825-01-personalized-learning-reminder|เอกสารระบบแนะนำส่วนบุคคล]])
  2. **แอดมินต้องยืนยันความเหมาะสม (approve)** ก่อนที่นักศึกษาคนนั้นจะได้รับสิทธิ์เป็นผู้แนะนำจริง — ระบบจะไม่ให้สิทธิ์อัตโนมัติทันทีที่เข้าเกณฑ์เกรด
- ห้องแชทถูกจัดกลุ่ม **แยกตามรายวิชา** — นักศึกษาที่ลงทะเบียนเรียนวิชาเดียวกันจะอยู่ในห้องแชทเดียวกัน
- ขอบเขตการเข้าถึงห้องแชทของแต่ละวิชา จำกัดเฉพาะนักศึกษาที่ลงทะเบียนเรียนวิชานั้นอยู่ในภาคการศึกษาปัจจุบัน (สอดคล้องกับการจัดห้องแชทแยกตามรายวิชา)
- ทุกข้อความ/โพสต์ในห้องแชทต้อง **ผ่านการตรวจสอบก่อนเผยแพร่ (pre-moderation)** โดยผู้ดูแลระบบหรือผู้ที่ได้รับมอบหมาย ก่อนที่นักศึกษาคนอื่นจะเห็นข้อความนั้น

_(ต้องการข้อมูลเพิ่มเติมจากผู้ใช้ในขั้นตอนถัดไป: ค่าตัวเลขที่แน่นอนของเกณฑ์เกรด/GPA ที่ใช้เสนอชื่อผู้แนะนำ, ผู้รับผิดชอบ pre-moderation คือแอดมินส่วนกลางหรืออาจารย์ประจำวิชา, SLA ของการตรวจสอบเนื้อหาก่อนเผยแพร่)_

## ขอบเขต (Scope)

### อยู่ในขอบเขต (In Scope)

- ห้องแชทกลุ่มแยกตามรายวิชา สำหรับนักศึกษาที่ลงทะเบียนวิชานั้น
- กลไกระบบเสนอชื่อนักศึกษาที่เข้าเกณฑ์ผลการเรียนสูงเป็นผู้แนะนำ/ผู้รีวิว
- ขั้นตอนแอดมินยืนยันความเหมาะสม (approve) ก่อนให้สิทธิ์ผู้แนะนำ
- การตรวจสอบเนื้อหาก่อนเผยแพร่ (pre-moderation) สำหรับทุกข้อความในห้องแชท

### ไม่อยู่ในขอบเขต (Out of Scope)

- การให้คำแนะนำแบบอัตโนมัติจากระบบโดยไม่มีนักศึกษาจริงเป็นผู้ให้คำแนะนำ (ครอบคลุมแล้วในเอกสาร [[20260825-01-personalized-learning-reminder|ระบบเตือนและแนะนำแนวทางการเรียนส่วนบุคคล]])
- ห้องแชทหรือฟอรัมที่เปิดกว้างข้ามรายวิชา/ทั้งระบบโดยไม่จำกัดขอบเขตวิชา
- ฟีเจอร์เสริม เช่น การให้คะแนน/รีวิวผู้ให้คำแนะนำ หรือระบบรายงานเนื้อหาไม่เหมาะสมภายหลังโพสต์ (post-moderation) — ยังไม่ระบุความต้องการในเวอร์ชันนี้
