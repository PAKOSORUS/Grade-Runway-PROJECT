# ระบบเตือนและแนะนำแนวทางการเรียนส่วนบุคคล

**วันที่สร้าง:** 2026-08-25
**สถานะ:** New

## ภาพรวม (Overview)

ระบบที่ช่วยติดตามสถานการณ์การเรียนของนักเรียน/นักศึกษา โดยพิจารณาจากหลายตัวแปรร่วมกัน (เกรด/ผลการเรียน, การเข้าเรียน, การส่งงาน, แนวโน้มผลการเรียน) แล้วแจ้งเตือนผู้เรียนเมื่อเข้าเงื่อนไขที่มีความเสี่ยง พร้อมให้คำแนะนำแนวทางการเรียนที่คำนวณเฉพาะบุคคลจากข้อมูลย้อนหลังของผู้เรียนแต่ละคน

ระบบต้องออกแบบให้เงื่อนไขการแจ้งเตือนและหมวดหมู่ผู้ใช้งานสามารถกำหนดค่าได้ (configurable) เพื่อให้ในอนาคตสามารถนำแนวคิด/สถาปัตยกรรมเดียวกันไปปรับใช้กับบริบทอื่นนอกเหนือจากการเรียนได้ (เช่น การติดตามผลการทำงานในองค์กร) — แต่ **ขอบเขตของเวอร์ชันนี้ยังคงจำกัดอยู่ที่บริบทการเรียนของนักเรียน/นักศึกษาเท่านั้น**

## User Stories / Use Cases

- ในฐานะนักเรียน/นักศึกษา ฉันต้องการได้รับการแจ้งเตือนเมื่อผลการเรียนหรือพฤติกรรมการเรียนของฉันเข้าเงื่อนไขที่มีความเสี่ยง เพื่อที่จะปรับตัวได้ทันเวลาก่อนปัญหาลุกลาม
- ในฐานะนักเรียน/นักศึกษา ฉันต้องการเห็นคำแนะนำแนวทางการเรียนที่คำนวณเฉพาะสำหรับฉันจากข้อมูลผลการเรียนย้อนหลัง เพื่อให้คำแนะนำตรงกับสถานการณ์จริงของฉัน ไม่ใช่คำแนะนำสำเร็จรูปเดียวกันสำหรับทุกคน
- ในฐานะนักเรียน/นักศึกษา ฉันต้องการเห็นสรุปภาพรวมสถานการณ์การเรียนของตัวเองแบบรายสัปดาห์ นอกเหนือจากการแจ้งเตือนแบบทันที
- ในฐานะผู้ดูแลระบบ ฉันต้องการปรับแต่งเกณฑ์/ตัวแปรที่ใช้ในการแจ้งเตือนได้ เพื่อให้ระบบยืดหยุ่นพอจะนำไปปรับใช้กับบริบทอื่นได้ในอนาคต

## Business Rules

- เงื่อนไขการแจ้งเตือนต้องพิจารณาจาก **หลายตัวแปรร่วมกัน** ไม่จำกัดเพียงตัวแปรเดียว อย่างน้อยประกอบด้วย:
  - เกรด/ผลการเรียนต่ำกว่าเกณฑ์ที่กำหนด
  - อัตราการขาดเรียนเกินเกณฑ์ที่กำหนด
  - การไม่ส่งงาน/ไม่ทำแบบทดสอบเกินจำนวนที่กำหนด
  - แนวโน้มผลการเรียนลดลงต่อเนื่องในหลายช่วงเวลา
- เกณฑ์ของแต่ละตัวแปรข้างต้นต้องเป็นค่าที่ **กำหนดค่าได้ (configurable)** ห้าม hardcode ตายตัวในระบบ
- คำแนะนำแนวทางการเรียนต้องเป็นคำแนะนำ **เฉพาะบุคคล** โดยคำนวณจากข้อมูลผลการเรียน/พฤติกรรมย้อนหลังของผู้ใช้แต่ละคน
- ช่องทางแจ้งเตือนเริ่มต้นของเวอร์ชันนี้: แจ้งเตือนในระบบ (in-app) ทันทีที่ตรวจพบเงื่อนไข ร่วมกับสรุปภาพรวมรายสัปดาห์ — สถาปัตยกรรมควรออกแบบให้เพิ่มช่องทางอื่นในอนาคตได้ (เช่น อีเมล, LINE) โดยไม่ต้องแก้โครงสร้างหลัก

_(ต้องการข้อมูลเพิ่มเติมจากผู้ใช้: ค่าตัวเลขที่แน่นอนของแต่ละเกณฑ์ เช่น เกรดต่ำกว่าเท่าใด ขาดเรียนกี่ครั้งถึงจะแจ้งเตือน — ยังไม่ได้ระบุ ควรกำหนดค่าตั้งต้นในขั้นตอนการออกแบบถัดไปที่ [[../../02-design/02-technical/index|02-technical]])_

## ขอบเขต (Scope)

### อยู่ในขอบเขต (In Scope)

- การติดตามตัวแปรผลการเรียนของนักเรียน/นักศึกษา (เกรด, การเข้าเรียน, การส่งงาน, แนวโน้ม)
- การแจ้งเตือนแบบ in-app + สรุปภาพรวมรายสัปดาห์ เมื่อเข้าเงื่อนไขที่กำหนด
- การให้คำแนะนำแนวทางการเรียนเฉพาะบุคคลจากข้อมูลย้อนหลัง
- การออกแบบเงื่อนไข/หมวดหมู่ผู้ใช้งานให้ปรับค่าได้ (configurable) เพื่อรองรับการขยายไปใช้บริบทอื่นในอนาคต (ออกแบบไว้เผื่อ ยังไม่ implement การใช้งานจริงนอกบริบทการเรียน)

### ไม่อยู่ในขอบเขต (Out of Scope)

- การนำระบบไปใช้งานจริงในบริบทองค์กร/บริษัท — เป็นเพียงแนวทางออกแบบให้รองรับในอนาคต ยังไม่ implement ในเวอร์ชันนี้
- ช่องทางแจ้งเตือนอื่นนอกเหนือจาก in-app เช่น อีเมล, LINE, SMS — เป็น future extension
- การเชื่อมต่อกับระบบเกรด/ระบบภายนอกอื่นที่ยังไม่ได้ระบุแหล่งข้อมูลชัดเจน (ต้องยืนยันเพิ่มเติมในขั้นตอนถัดไป)
